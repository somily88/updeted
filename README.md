# صبحي تريدر

بوت تداول Spot تجريبي لـ Binance مع لوحة تحكم عربية، ومراقبة الأزواج BTC/USDT وETH/USDT وBNB/USDT وSOL/USDT وXRP/USDT وADA/USDT.

حد الصفقات مستقل لكل سوق: حتى 6 صفقات Spot و6 مراكز Futures Demo. يمكن ضبط كل حد على حدة عبر `MAX_SPOT_CONCURRENT_TRADES` و`MAX_FUTURES_CONCURRENT_TRADES` أو إعدادات التطبيق.

## تشغيل محلي عبر Docker

1. انسخ `.env.example` إلى ملف باسم `.env`.
2. استخدم مفاتيح Binance Demo فقط، وأنشئ كلمة مرور للوحة ومفتاح تشفير فريدًا لهذا التثبيت.
3. اترك `BINANCE_ENV=demo` و`TRADING_ENABLED=false` أثناء الإعداد الأولي. لتجربة أوامر Demo، أضف مفاتيح Demo واضبط `TRADING_ENABLED=true` بعد التحقق من الإعدادات.
4. شغّل `docker compose up -d --build`.
5. افتح `http://localhost:8010/`.

يقتصر نشر Docker الافتراضي على `127.0.0.1`. لا تفتح اللوحة على الإنترنت مباشرة.

## حماية المفاتيح

لا ترفع `.env` أو `env.txt` أو أي مفاتيح API أو كلمات مرور إلى GitHub. لا تمنح مفاتيح Binance صلاحية السحب. التنفيذ الآلي في هذا الإصدار مقفل على Binance Demo ولا يرسل أوامر Spot إلى البيئة الحية.

## حدود الحماية الآلية

- يظل التنفيذ مقفلاً على Binance Demo في مسارات Spot وFutures. يضع البوت أوامر وقف حماية على Demo للصفقات المُدارة، ويطابق المراكز والأوامر بعد إعادة التشغيل. إذا تعذر تأكيد الوقف أو اختلف الرصيد عن السجل، يجمّد المركز والدخول الجديد حتى تظهر المطابقة في سجل القرارات.
- تُحسب المخاطرة المفتوحة مجتمعة بين Spot وFutures Demo. الحد الافتراضي للمحفظة 8% من الرصيد، وحد مجموعة الأصول المترابطة 4%؛ يمكن ضبطهما عبر `MAX_PORTFOLIO_OPEN_RISK_PCT` و`MAX_CORRELATED_CLUSTER_RISK_PCT`.
- يحتفظ سجل الصفقات بصافي Spot ورسومه المقدرة أو الفعلية. تفصيل الرسوم القديمة التي لم تكن محفوظة يبقى تقديريًا أو غير متاح، بينما Futures يعرض إجمالي الربح والرسوم والتمويل والصافي.

تُراقَب أوامر وقف الخسارة والهدف داخل التطبيق عند كل دورة فحص؛ هذه النسخة لا تضع أوامر وقف حماية مستقلة على Binance. إذا توقف التطبيق أو انقطع اتصاله، فلن ينفذ الوقف حتى عودة الخدمة. كما يوقف البوت فتح مراكز جديدة إذا أصبحت الأسعار قديمة أو تعذرت مطابقة أمر إغلاق.

## الاستراتيجيات

يقيّم محرك الإشارات تتبّع الاتجاه والاختراق والارتداد، ويضيف هجين الزخم الكلي، وخوارزميًا يستخدم الأخبار كسياق، وتداول نطاق حجم التداول. الأخبار وحدها لا تنشئ إشارة. تحوّط اختراق التقلب مخصص لـ Binance Futures Demo فقط، ولا يفتح إلا مقابل تعرض Spot طويل مطابق، ويُحدّث أو يُغلق عند انخفاض ذلك التعرض. النسبة الافتراضية القصوى 50% ويمكن تعديلها عبر MAX_SPOT_HEDGE_RATIO. أزواج Futures المشفرة المضافة لهذا المسار مخصصة للتحوط فقط ولا تفتح صفقات مستقلة.

الاختبار التاريخي لا يحاكي التحوّط المرتبط بمراكز Spot، ولا يملك سجلًا تاريخيًا للأخبار؛ لذلك لا تعد نتائجه دليلًا على أداء الاستراتيجيات الهجينة كاملة. يستخدم الاختبار نوافذ OOS متتابعة؛ رسوم التداول الافتراضية توضيحية، ويمكن تمرير رسوم حسابك عبر `--fee-percent` لكنها لا تُقرأ تلقائيًا من Binance.
## الاختبار قبل الاستخدام

راجع الاستراتيجية وإدارة المخاطر بنفسك، واستخدم الاختبار التاريخي وخارج العينة ثم Paper Trading أو Binance Demo. نتائج backtest لا تضمن نتائج مستقبلية، وهذا المشروع ليس نصيحة استثمارية.
