# صبحي تريدر

بوت تداول Spot تجريبي لـ Binance مع لوحة تحكم عربية، ومراقبة الأزواج BTC/USDT وETH/USDT وBNB/USDT وSOL/USDT وXRP/USDT وADA/USDT.

## تشغيل محلي عبر Docker

1. انسخ `.env.example` إلى ملف باسم `.env`.
2. استخدم مفاتيح Binance Demo فقط، وأنشئ كلمة مرور للوحة ومفتاح تشفير فريدًا لهذا التثبيت.
3. اترك `BINANCE_ENV=demo` و`TRADING_ENABLED=false` أثناء الإعداد الأولي. لتجربة أوامر Demo، أضف مفاتيح Demo واضبط `TRADING_ENABLED=true` بعد التحقق من الإعدادات.
4. شغّل `docker compose up -d --build`.
5. افتح `http://localhost:8010/`.

يقتصر نشر Docker الافتراضي على `127.0.0.1`. لا تفتح اللوحة على الإنترنت مباشرة.

## حماية المفاتيح

لا ترفع `.env` أو `env.txt` أو أي مفاتيح API أو كلمات مرور إلى GitHub. لا تمنح مفاتيح Binance صلاحية السحب. استخدم حساب Demo للاختبار؛ تغيير متغيرات البيئة إلى `live` قد يتيح تداولًا حقيقيًا وفق منطق التطبيق.

## الاختبار قبل الاستخدام

راجع الاستراتيجية وإدارة المخاطر بنفسك، واستخدم الاختبار التاريخي وخارج العينة ثم Paper Trading أو Binance Demo. نتائج backtest لا تضمن نتائج مستقبلية، وهذا المشروع ليس نصيحة استثمارية.
